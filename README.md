# corCPR — тренажёр СЛР по камере
Веб-приложение, которое учит технике непрямого массажа сердца (СЛР) через обычную веб-камеру, без установки программ и без манекена.

**Направление:** Фитнес-тренер / Здоровье и технологии
**Ссылка на рабочий сайт:** (https://v0-corcpr.vercel.app)
**Репозиторий:** (https://github.com/nien83420-art/CorCPR)

## 💡 Идея
Свидетели помогают при остановке сердца лишь в части случаев, и одна из причин — неуверенность в собственной технике. corCPR даёт живую обратную связь по позе и темпу прямо во время тренировки, чтобы человек мог потренироваться заранее и увереннее действовать в реальной ситуации — то есть научиться помогать другому.

## Движения / Возможности
1. **Рука у уха** — запуск тренировки, напоминает, что нужно позвонить в скорую.
2. **Локти прямые** — приложение проверяет угол в локтях во время компрессий.
3. **Кисти вместе** — приложение проверяет, что руки сложены правильно.
4. **Темп компрессий** — приложение считает нажатия в минуту в реальном времени (норма 100-120 в минуту).

## Как это работает (Локальный запуск)
Для локального запуска CorCPR необходимо:
- *Node.js 20 или новее*
- *pnpm 12 или новее*
- *Git*
- Современный браузер с поддержкой веб-камеры
- Веб-камера для работы системы распознавания позы

### Установка (Installation)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/nien83420-art/CorCPR.git
   ```

2. Перейдите в папку проекта:
   ```bash
   cd CorCPR
   ```

3. Установите зависимости:
   ```bash
   pnpm install
   ```

4. Запустите приложение в режиме разработки:
   ```bash
   pnpm dev
   ```

5. Откройте приложение в браузере:
    `http://localhost:3000`

> 💡 При первом запуске тренировки браузер запросит разрешение на использование веб-камеры. Доступ к камере необходим для корректной работы MediaPipe Pose Landmarker.

### Конфигурация 
Для базового запуска CorCPR не требуются API-ключи или файл `.env`. Обработка позы выполняется с помощью MediaPipe Pose Landmarker непосредственно во время работы веб-приложения на стороне клиента.

- **GitHub** — хранение исходного кода и контроль версий.

### ИИ и компьютерное зрение
corCPR использует **MediaPipe Pose Landmarker** для распознавания позы человека в реальном времени через веб-камеру.

MediaPipe определяет координаты ключевых точек тела (landmarks), после чего собственная алгоритмическая логика corCPR обрабатывает эти данные для:
- стабилизации распознавания позы;
- распознавания жеста вызова помощи (CALL_HELP);
- проверки положения рук, запястий, локтей и плеч;
- определения полных циклов компрессий;
- подсчёта количества компрессий;
- определения темпа компрессий;
- формирования обратной связи по положению тела и движениям;
- сбора статистики тренировки и формирования итогового результата.

Таким образом, **MediaPipe отвечает за распознавание позы**, а анализ техники СЛР, подсчёт движений и формирование обратной связи выполняются алгоритмической логикой corCPR.

### Тестирование
Проект тестировался вручную в браузере с использованием веб-камеры. Основное внимание уделялось корректности распознавания позы, переходам между этапами тренировки и подсчёту компрессий.

### Проверяемые сценарии:
* **CALL_HELP** — распознавание жеста вызова помощи при расположении руки возле головы.
* **HAND_POSITION** — проверка положения рук, запястий, локтей и плеч перед началом компрессий.
* **COMPRESSIONS** — проверка подсчёта только завершённых циклов движения вниз–вверх.
* Удержание правильной позиции без движения не должно увеличивать счётчик.
* Незавершённое движение не должно засчитываться как компрессия.
* Кратковременная потеря отдельных точек (landmarks) не должна сбрасывать текущий цикл.
* При неправильном положении рук система должна выводить соответствующую подсказку и визуальную индикацию.
* Проверялась работа интерфейса на трех языках: русском, казахском и английском.
* Проверялся полный пользовательский сценарий: Инструкция → CALL_HELP → HAND_POSITION → COMPRESSIONS → RESULTS.

### Контрольный тест счётчика
Для проверки алгоритма выполнялась серия из 10 отчётливых полных компрессионных движений. Ожидаемый результат — счётчик фиксирует 10 завершённых циклов, не учитывая статичное положение и незавершённые движения.

###  Режим «Ошибка»
Приложение не просто засчитывает правильные движения, но и находит конкретные ошибки:

1. **Если локти согнуты** — конкретный фрагмент скелета (локоть) подсвечивается красным, и выводится подсказка *«Выпрями локти»*.
2. **Если кисти не соединены** — аналогично подсвечивается фрагмент и выводится подсказка *«Сведи запястья вместе»*.
3. **Если темп слишком медленный** — выводится подсказка *«Ускорьтесь»* с ориентиром на норму 100-120 в минуту.
Подсказки конкретные и указывают, что именно исправить.

## Важная оговорка
Это учебный тренажёр темпа и позы. Он не заменяет очный курс первой помощи и не измеряет глубину нажатий только положение рук, локтей и частоту компрессий.
